# CineMatch AI 🎬

A premium, Netflix-style movie discovery and recommendation platform built using Python and Streamlit, powered by real-time data from The Movie Database (TMDb) API.

## 🚀 Features
- **Smart Search:** Search any movie to view its dynamic metadata, high-quality poster, release date, ratings, and plot overview.
- **AI-Driven Recommendations:** Automatically suggests up to 12 highly similar movies based on content metrics.
- **Genre Browsing:** Dedicated dynamic tabs to filter and view trending movies across genres like Thriller, Romance, Action, Comedy, and Sci-Fi.
- **Interactive Ratings:** Built-in interactive 5-star user rating system with session memory.

## 🛠️ Tech Stack
- **Frontend & UI:** Streamlit, Custom CSS
- **Backend:** Python
- **Data Source:** TMDb API (The Movie Database)
